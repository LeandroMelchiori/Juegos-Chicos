# Mate Arcade

Juego educativo de matemática perteneciente a la colección Juegos Chicos.

## Entrada

`index.html`

## Contenido

- Modos Arcade, Práctica y Repaso adaptativo.
- Diez temas matemáticos.
- Microlecciones y mini evaluaciones.
- Herramientas de consulta.
- Progreso local por perfil.

`guia-original.html` es una versión histórica de la guía y no es requerida por el juego.

Para volver al catálogo se utiliza el enlace “Juegos” en la esquina superior izquierda.
