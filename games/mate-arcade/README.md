# Mate Arcade

Juego educativo de matemática perteneciente a la colección Juegos Chicos.

## Entrada

`index.html`

## Contenido

- Modos Arcade, Práctica y Repaso adaptativo.
- Diez temas matemáticos.
- Microlecciones y mini evaluaciones.
- Herramientas de consulta.
- Progreso local por perfil.
- Correcciones relacionadas con el error elegido.
- Repaso basado en evidencia reciente, dificultad y reaparición espaciada.
- Modo visual sin puntaje, reloj ni rachas.

## Archivos

- `index.html`: estructura y entrada distribuible.
- `styles.css`: presentación responsive, contraste y movimiento reducido.
- `js/lessons.js`: contenido pedagógico de las diez lecciones.
- `js/app.js`: juego, perfiles, progreso y accesibilidad.

Todos los recursos necesarios son locales y funcionan también al abrir `index.html` directamente.

`guia-original.html` es una versión histórica de la guía y no es requerida por el juego.

Para volver al catálogo se utiliza el enlace “Juegos” en la esquina superior izquierda.
